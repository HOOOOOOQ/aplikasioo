## 2. Yang diperbaiki pada audit ini

### 2.1 Kode mati yang menyesatkan

`accessTokenExpiry()` di `student_identity_provider.dart` mengurai payload token
sebagai **integer**:

```dart
final exp = int.tryParse(parts[1]);   // payload JWT base64url, bukan angka
```

Fungsi ini **selalu** mengembalikan `null` dan tidak pernah dipanggil di mana
pun. Token siswa EduTask juga bukan JWT murni (`payload.signature` dengan HMAC
server), sehingga asumsi "bagian ke-2 = exp" tidak berlaku. Fungsinya dihapus
agar tidak dipakai ulang secara keliru.

### 2.2 Penanganan koneksi terputus (sebelumnya tidak ada)

`connectivity_plus` sudah ada di `pubspec.yaml` tetapi **tidak dipakai sama
sekali** — pengguna tidak mendapat petunjuk apa pun ketika jaringan putus dan
tombol-tombol tampak gagal tanpa alasan.

Yang ditambahkan:

* `NetworkStatus` (`online` / `offline` / `unknown`) dengan fungsi murni
  `fromResults()` yang bisa diuji tanpa plugin.
* `ConnectivityService` + `networkStatusProvider` yang **tidak pernah** melempar
  exception ke UI (plugin tidak tersedia → `unknown`).
* `AppConnectivityBanner`: pita tipis "Tidak ada koneksi internet" yang memakai
  `IgnorePointer` sehingga **tidak** menghalangi AppBar atau tombol di bawahnya.

Keputusan penting: status `unknown` (daftar hasil kosong, plugin gagal)
**tidak** menampilkan peringatan. Banner juga tidak memblokir operasi apa pun —
setiap permintaan tetap dicoba dan kegagalan dilaporkan `AppError`. Alasannya,
"ada tautan jaringan" tidak menjamin Supabase terjangkau (captive portal, DNS,
proxy sekolah).

### 2.3 Navigasi & refresh URL kini bisa diuji

Kebijakan redirect dipindah dari closure `GoRouter` ke fungsi murni
`resolveRedirect({path, auth})` di `app_router.dart` — **perilaku tidak
berubah**. Dengan ini skenario yang sebelumnya hanya bisa diuji manual menjadi
tes otomatis:

* `/splash`, `/onboarding`, `/login`, `/tentang` publik;
* seluruh `/siswa/**` publik (memakai kode akses);
* `/admin/**` & `/guru/**` wajib login + akun aktif + peran cocok;
* **selama profil dimuat → `/splash`, bukan `/login`** (mencegah "terlempar ke
  login" saat refresh halaman Web);
* guru membuka `/admin` → `/guru`; peran tidak dikenal → `/login`;
* error memuat profil diperlakukan sebagai belum login.

### 2.4 Alat pengembangan Web

`scripts/web/run_web.sh` sekarang:

* mendukung `WEB_DEVICE=chrome` (untuk `flutter run -d chrome`, sesuai permintaan)
  maupun `web-server` (default, untuk Termux/SSH tanpa Chrome);
* mencetak **alamat LAN** otomatis ketika `WEB_HOST=0.0.0.0` agar bisa dibuka
  dari HP lain di Wi-Fi yang sama (Linux/Termux `hostname -I`, macOS
  `ipconfig getifaddr`);
* tetap menolak berjalan tanpa `SUPABASE_URL`/`SUPABASE_ANON_KEY` dan tidak
  pernah mencetak isi anon key.

## 3. Yang diaudit dan **ternyata sudah benar** (tidak diubah)

Hal-hal berikut sering menjadi sumber bug, jadi diperiksa satu per satu dan
hasilnya sudah benar. Semuanya punya tes.

| Area | Berkas | Temuan |
|---|---|---|
| Back Android | `core/navigation/back_guard.dart` | Sudah dipasang untuk **admin, guru, dan siswa** lewat `ShellRoute`/`_siswaGuard`; satu tekan = satu aksi, konfirmasi hanya di akar, `SystemNavigator.pop()` tidak dipakai untuk navigasi biasa, latch 250 ms mencegah double-tap |
| Sesi | `core/services/session_guard.dart` | 401/403 **tidak** dianggap sesi habis; jaringan gagal ≠ sesi dicabut (token lama dipakai, `degraded`), refresh lewat mekanisme GoTrue, retry sekali pada 401 |
| Profil | `auth/data/auth_repository.dart` | Error memuat profil **tidak** ditelan (splash menampilkan "gagal memuat" + coba lagi, bukan pura-pura logout) |
| Kode akses | `access_codes/data/*`, `supabase/functions/student-access` | Kode dibuat server (CSPRNG), disimpan sebagai hash, verifikasi server, klaim atomik, idempotency key, retry 401 setelah refresh |
| Web & `dart:io` | `core/services/csv_saver*` | Hanya satu berkas memakai `dart:io`, diisolasi lewat conditional export (`csv_saver_stub.dart` untuk Web) |
| Lampiran | `teacher_task_form_page.dart` | Memakai `file.bytes` (bukan `file.path`), jadi berfungsi di Web; validasi ukuran/ekstensi di klien **dan** di service |
| Chat | `chat_room_page.dart` | Halaman 30 pesan, "muat lebih banyak", Supabase Realtime, channel dilepas di `dispose` |
| Dependency | `pubspec.yaml` | `image` di-pin `<4.11.0` karena `pdf` membatasi `archive <4.1.0` (kalau dilepas, build gagal `decodeLazy`) |

## 4. Yang sengaja **tidak** diubah

| Hal | Alasan |
|---|---|
| **Mode gelap** | `darkTheme` saat ini mengembalikan tema terang. Palet `AppColors` dipakai **568 kali**, 179 di antaranya di dalam ekspresi `const`, sehingga mengubahnya menjadi dinamis berarti menyentuh ratusan berkas sekaligus — bertentangan dengan batasan "perubahan bertahap, jangan migrasi massal". Opsi gelap **tidak** ditampilkan di UI, jadi tidak ada kontrol palsu (tidak ada tombol yang tampak aktif tetapi tidak berfungsi) |
| 508 pemakaian `AppColors.*` | batasan pengguna |
| Alur auth/JWT, `applicationId`, signing key | batasan pengguna |
| Lima rute dengan AppBar ganda | batasan pengguna |
